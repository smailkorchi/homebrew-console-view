# Console View Homebrew tap

Install [Console View](https://github.com/smailkorchi/console-view) with [Homebrew](https://brew.sh):

```sh
brew install --cask smailkorchi/console-view/console-view
```

Requires macOS 14 Sonoma or later. Homebrew selects the Apple Silicon or Intel download for your Mac and verifies its SHA-256 checksum before installing `Console View.app` in Applications.

Console View is ad-hoc signed and is not notarized by Apple. If macOS blocks the first launch, review the [source](https://github.com/smailkorchi/console-view) and [release](https://github.com/smailkorchi/console-view/releases/tag/v1.0.0), then use System Settings → Privacy & Security → Open Anyway if you trust it. This tap does not change macOS security settings.
